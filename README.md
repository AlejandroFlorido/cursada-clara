# Cursada Clara

Web con herramientas para estudiantes universitarios con TDAH o dificultades de aprendizaje. Nombre provisorio.

El proyecto se organiza en tres líneas:

- **Informar:** qué es el TDAH, mitos y realidades, situaciones típicas de la cursada.
- **Orientar:** traductor de consignas, mapa de la cursada, códigos visuales.
- **Acompañar:** primer paso, dividir la entrega, calendario semanal, bloques de estudio.

Incluye además una sección para docentes con una plantilla de consigna clara.

## Cómo verlo

Es un sitio estático en un solo archivo. Abrí `index.html` en el navegador. Los datos que carga cada estudiante quedan solo en su navegador (localStorage).

Nota: `index.html` no tiene `<html>`, `<head>` ni `<body>` porque nació como prototipo publicado; los navegadores lo muestran igual.
